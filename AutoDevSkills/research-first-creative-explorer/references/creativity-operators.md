# Creativity operators (Phases D–E)

Divergence is a skill, not luck. Use explicit operators so the ideas are
genuinely different in *mechanism*, not just in name or branding. Never filter for
feasibility here — that is Phase F.

## The seven concept classes (Phase D)

Produce ideas in **each** class. If a class is empty, you have not diverged enough.

1. **Adjacent** — feasible, close to current behavior. The low-risk baseline.
2. **Cross-domain** — borrow a working mechanism from a *completely different*
   field (biology, logistics, theatre, sport, religion, games…) and transplant it.
3. **Frontier** — ride a newly-available capability, trend, or shift (a new
   sensor, law change, material, behavior, price collapse).
4. **Strange-but-coherent** — looks odd at first glance but solves a real need
   when you follow the logic. Should make a reader pause, then nod.
5. **Speculative** — explores a future or behavior not yet common; a "what if this
   became normal?" probe (speculative / design-fiction thinking).
6. **Non-software** — an object, place, service, event, ritual, kit, format, or
   institution. Include this class even for "tech" briefs; it stress-tests whether
   software is actually required.
7. **Rule-breaking** — invert a foundational assumption of the domain (pricing,
   ownership, timing, who does the work, what the product even is).

Each idea must state a **novelty mechanism**: one sentence naming *precisely* what
makes it different (a new mechanism, an unusual combination, an inverted
assumption, an untapped resource, a new context/moment). "AI-powered" is not a
novelty mechanism. If you cannot name it, the idea is not novel yet.

## Named divergence techniques (how to generate)

- **First-principles** — strip the problem to its irreducible truths, ignore how
  it's "always done", rebuild upward. Kills inherited-form assumptions.
- **Analogical / cross-domain transfer (synectics)** — "what solves a problem of
  this *shape* elsewhere?" Map the source mechanism onto the target. This is the
  richest source of surprising-yet-logical ideas.
- **Morphological analysis** — list the independent parameters of a solution (who,
  medium, moment, value model, interaction…), enumerate options per parameter,
  then combine across columns — especially unlikely combinations.
- **Inversion** — negate a core assumption: reverse the flow, the payer, the
  actor, the timing, the goal. ("What if the user never opens it?")
- **Lateral thinking** — provocation & escape: state a deliberately absurd premise,
  then extract the usable idea from it.
- **Speculative / design-fiction** — imagine the world in which this is normal and
  work backward to a first artifact for today.
- **Constraint-as-feature** — take the harshest limitation and make it the point
  (limited time, no screen, no internet, one-time use).

## Mutation & synthesis prompts (Phase E)

Take the interesting seeds and run them through mutations until concepts stop
reading as clones of a popular product:

- Invert how it works entirely.
- Remove the screen. Remove the phone. Remove the internet.
- Make it exist for only one minute / one day / once in a lifetime.
- Make it ambient — the user never actively opens it.
- Make it generated by the community, the environment, or real-world behavior.
- Don't charge the user — who else values this, and would pay?
- Make it a ritual / world / game / physical object / service instead of an app.
- Fuse two unrelated ideas from your list into one.
- Serve a very narrow group with an extremely strong need.
- Turn the biggest limitation into the central feature.
- **The subtraction test:** if AI/software vanished, what core value remains? If
  nothing remains, the value was decoration — rebuild it.

## Anti-patterns (do NOT do these while diverging)

- Reject an idea because it's hard to build (that's Phase F).
- Force an idea to fit the user's existing stack.
- Shrink to an MVP too early.
- Turn every idea into a chatbot, marketplace, dashboard, or content generator.
- Generate 20 variants of one concept and call it diversity.
- Use "AI-powered" to hide the absence of new value.
